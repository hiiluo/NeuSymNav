## Observation availability

| Field | Trước linker | Trong evidence live đã publish |
| --- | --- | --- |
| Detection ID, frame ID | `Detection.detection_id` là index của result, duy nhất trong batch. `FrameKey` gồm episode/sensor/frame | Có ID và FrameKey. Run lấy từ native token |
| Persistent Object ID | Detection chưa có ID. Legacy track, Paper CID và native raw ID là các namespace khác nhau | Endpoint thuộc exact revision. Canonical ID chỉ resolve nếu lineage view chứng nhận |
| Category, score, class scores | Raw text, canonical category, score top-1. Không có logits/full vector trên interface | `DetectionGeometry` mang canonical category khi link. `ObservationEvidence` và các row `refs/links` live không persist raw/canonical detector category hoặc score |
| Embedding | YOLOE result adapter không publish per-instance embedding. CLIP/appearance là pipeline riêng | Có thể tạo offline từ crop, dùng `FeatureSpec` riêng |
| Mask và box | Mask full-resolution. Bbox derive từ mask, không copy detector XYXY | Crop RGB/mask/depth/valid + SHA, pixel bbox XYXY và asset path |
| Timestamp và pose | Capture monotonic ns, clock domain, calibrated pose và frame geometry hash | Timestamp, domain, pose version, calibration và hash trong ref. Pose đầy đủ cần join source journal |
| Association | Không có probability calibrated | Status, geometric IoU và policy version. `native_confirmed` yêu cầu `native_lineage_sha256` ở contract nhưng producer này không tạo trạng thái đó |
| Provenance | Detector checkpoint/profile, vocabulary, calibration và frame | Source pins và exact native token/prefix. `last_source` chỉ là metadata của graph revision |

## Native source và probe

Local source Hydra ở `2e58a35baea629eee8838409771876acff015daf`, Spark-DSG ở `3c40997e4ae739c56ed3cdd6ef5e882d403d8b64`, cả hai clean và trùng lock local. Runtime probe dùng binding và bridge từ profile ghi trong kết quả. `MeshSegmenter::detect` phân vùng mesh theo semantic label, `updateGraph` tra `active_nodes_.at(label)`, `mergeActiveNodes` chỉ xét cùng bucket. `UpdateObjectsFunctor::Config` mặc định `SemanticNearestNode`. [Hydra frontend](https://github.com/MIT-SPARK/Hydra/blob/2e58a35baea629eee8838409771876acff015daf/src/frontend/mesh_segmenter.cpp) · [Hydra backend](https://github.com/MIT-SPARK/Hydra/blob/2e58a35baea629eee8838409771876acff015daf/include/hydra/backend/update_objects_functor.h) · [Spark-DSG pin](https://github.com/MIT-SPARK/Spark-DSG/tree/3c40997e4ae739c56ed3cdd6ef5e882d403d8b64).

Hydra paper mô tả ESDF, places và room topology. ReasoningGraph paper thêm object/room semantic features và object relations từ VLM. Official ReasoningGraph dùng ROS và tham chiếu `semantic_inference_ros` cho semantic/reasoning models. Ma trận ở trên chấm actual Python/native paths của NeuSymNav và bằng chứng runtime tương ứng. [Hydra paper](https://arxiv.org/abs/2201.13360) · [ReasoningGraph paper](https://arxiv.org/abs/2602.02456) · [Project](https://ntnu-arl.github.io/reasoning_graph/) · [reasoning_hydra](https://github.com/ntnu-arl/reasoning_hydra) · [semantic_inference_ros](https://github.com/ntnu-arl/semantic_inference_ros).

Taxonomy có native ID 18 cho `chair`, 2 cho `armchair`, 49 cho `sofa`. `couch` canonicalize thành `sofa`. Hai arm dùng cùng view thật 00806, mask 10.025 pixel, RGB-D, pose và 12 timestamp cố định. Chỉ raster label của mask đổi. Arm `chair` giữ `O(0)`. Arm flip có `O(0)`, `O(1)` từ bước 7, `O(2)` từ bước 11, cả ba active và trùng vị trí ở bước 12. Lặp mỗi label cho semantic integration tích lũy quan sát, đây là can thiệp chẩn đoán, không đo lỗi detector hay tần suất duplicate của episode thật. [Bảng số và artifacts](integration-results.md).

ReasoningGraph linker cũng loại endpoint khác category kể cả khi AABB trùng hoàn toàn, trước khi áp dụng overlap. Gỡ ngưỡng category ở linker đơn lẻ sẽ không giải quyết ba native IDs ở trên. Hiện kết quả 00806 frame-unique xác định được 9/13 liên kết đúng theo pilot. Hold-out 00770 còn 6/7 dự đoán chưa được phân giải. M1 bị chặn bởi cả continuity native cross-category và thiếu receipt detection→physical object đạt chuẩn. Không dùng gần nhau, overlap AABB, cùng raw ID hoặc native merge event đơn lẻ làm bằng chứng độc lập cho một physical instance.
