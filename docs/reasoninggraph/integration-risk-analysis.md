# Rủi ro tích hợp ReasoningGraph

| Rủi ro và mức độ | Tín hiệu / hậu quả | Mitigation, gate và rollback |
| --- | --- | --- |
| **Cao — Hai identity domains.** Hydra class raster mất instance IDs, CandidateMemory có CID riêng. | Adjacent same-label bị gộp, cached hints/relations gắn nhầm object. | Evidence join có unique 3D support. Merge/delete chỉ theo explicit lineage. Replays cùng lớp lấy false match và coverage. Nếu M1 thiếu proof, revision-local retrieval, khóa persistent relations/advisory. |
| **Cao — Native source/runtime lệch.** Install recipe bỏ RUNPATH nên hash differs, đối chiếu bản sao sau transform đã khớp byte. | Trace không tái lập, load ABI/schema khác. | Ghim loaded artifacts, output schema và library paths. M0 ghim build/install linkage đã kiểm và xác minh reproducibility từ source nếu cần isolated rebuild. Rollback cờ off, giữ native build hiện hành. [Audit](current-system-audit.md). |
| **Cao — Paper calibration thay đổi với tilt.** Hydra worker khóa calibration trong episode. | Paper shadow không nhận full frames, pose/room sai. | Gate analytic projection/depth + native room/places với fixed rig và camera-as-body test. Rút profile về fixed rig replay nếu không chứng minh full-coverage adapter. [M7](implementation-plan.md#m7--end-to-end-visualization-và-consumer-hiện-có). |
| **Cao — Visual token incompatibility.** Encoder/decoder/tiles/order/dtype lệch. | Có embedding nhưng decode không tương đương, relation hallucination hoặc OOM. | Pin paired checkpoint/layout, parity trên golden crop, không average incompatible tensors. Fallback semantic B3 hoặc crop-based arm riêng. |
| **Cao — Pair growth và GPU 6 GB.** N² pairs, tensor payloads có thể lớn. | Pending queue làm evidence stale, peak device/host vượt budget. | Sparse gates, quota/drop metrics, keyframe budgets, bounded carrier and hints, một workload GPU, remote option. Degrade tắt pair worker trước khi ảnh hưởng control. |
| **Cao — Snapshot/restart/merge/optimization.** Async output chạy qua graph revisions. | Orphans, circular aliases và duplicate counts sau retry. | Atomic manifest, CAS theo graph epoch/revision, endpoint tombstones và late reply checks. Match hash khi reopen. Discard/rebuild incomplete sidecar. |
| **Cao — Policy, verification và GT leakage.** Semantic match bị dùng như safety/verifier. | False STOP, action không đi qua planner, ObjectNav comparison sai. | Opt-in C tie-break sau existing filters, kiểm current-depth/path/STOP gates đúng runner. Nếu paper advice cần guard mới, dùng arm đối chứng cùng guard hoặc giữ shadow. GT ở evaluator, trace consumer và parity tests. Tắt advisory nếu bất kỳ bypass. |
| **Trung bình — Room clustering với chậm/split/merge.** | Room labels centroid bị kéo sang room khác, cache eviction bias. | Pose mapping + membership revision, reassign retained pools, coverage explicit và invalidate nếu thiếu corrected poses. |
| **Trung bình — Paper vs public config.** | Hai profile gọi chung faithful dù model/weights/crops khác. | Đặt paper-faithful, source-parity và local adaptation trong manifests riêng. Nối chính xác source pins/recipes. [Technical analysis](technical-analysis.md). |
| **Trung bình — External API drift, latency, chi phí và dữ liệu.** | Độ trễ/cost thay đổi, model version hoặc payload remote không phù hợp điều khoản. | Explicit endpoint/version, bounded budget, latency/cost log, xác minh terms cho dataset/weights, TLS và metadata scrub, opt-in. CPU/off fallback. |
| **Trung bình — Exposure rất thấp ở advisory.** | SR gần bằng baseline dù improved retrieval. | Báo coverage, eligibility và selection_changed. Kết luận dựa trên usage. Đánh giá relational set độc lập. |

## Môi trường và license gates

Host xác minh Ubuntu 24.04.5 và cài ROS Jazzy, hydra workspace source môi trường Jazzy/native bindings. Runner paper là Habitat worker riêng. `nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv,noheader` exit 9 ngày 2026-11-26 vì driver không giao tiếp được trong môi trường thực thi. RTX 3060 Laptop 6 GB hiện là mục tiêu thiết kế và profile cũ, chưa có thiết bị khả dụng được xác nhận trong audit. Upstream ReasoningGraph dùng ROS1 Noetic/Ubuntu 20.04 theo install recipe, tách test reference khỏi môi trường chính. [Audit local](current-system-audit.md), [upstream](technical-analysis.md).

- Bill of materials M0/M4 phải liệt kê package, commit/version, code LICENSE/NOTICE, model checkpoint terms, dependencies lock, data terms và distribution scope. Review theo đúng resolved pin và artifact. Git ref, installer branch name hoặc badge không cấp quyền cho weights/datasets. [Third-party notices](../../THIRD_PARTY_NOTICES.md), [upstream dependency inventory](technical-analysis.md).
- Hydra và Spark-DSG local dùng BSD-2-Clause ở các checkout đã pin. Metadata copyright Ubuntu local cho Eigen 3.4.0 ghi MPL-2 và các notices theo file. PCL 1.14 ghi BSD-3-Clause cùng notices bổ sung, OpenCV 4.6 ghi Apache-2.0, BSD-3-Clause và các notices theo file. GTSAM nằm trong sysroot snapshot, chưa kiểm license đúng package từ host dpkg. [Hydra LICENSE](https://github.com/MIT-SPARK/Hydra/blob/2e58a35baea629eee8838409771876acff015daf/LICENSE), [Spark-DSG LICENSE](https://github.com/MIT-SPARK/Spark-DSG/blob/3c40997e4ae739c56ed3cdd6ef5e882d403d8b64/LICENSE). Kiểm riêng upstream forks, semantic_inference, DeepSeek software và model license, OpenAI CLIP/OpenCLIP code + weights, Ultralytics/YOLOE và MobileCLIP, torch/CUDA, ROS/catkin, Kimera, config_utilities, Spatial-Hash, TEASER++, mesh and pose-graph dependencies, Qwen và HM3D/Replica theo deployment closure. Unknown/missing exact terms là blocker để đưa dependency đó vào profile được phân phối, có thể tiếp tục fixtures và interface-level methods.
- ApexNav GPL-3.0 là dependency tương lai. Record license và phần tự triển khai theo paper, xin review phạm vi linkage/distribution trước sao chép/đóng gói. Repo khác và model terms có status trong [future roadmap](future-module-integration-roadmap.md). Giữ license project theo repo hiện tại.
- Kiểm GPU workload bằng khóa native dùng chung. Một load/profiling run một thời điểm. Không dùng số của Jetson Orin để đạt ngưỡng máy local. Image/text/relational results đẩy bounded từ worker. Consumer control chỉ đọc snapshot. Mỗi profile có kill switch và explicit degraded mode.
